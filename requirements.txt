# Every entry maps a third-party *import* name used in the scripts to its
# actual PyPI package name (see the comment above each entry). Bounds are
# chosen so that a Python 3.8 interpreter can still resolve a compatible
# release (pip picks the newest version whose Requires-Python allows yours).
#
# Development/CI tooling lives in requirements-dev.txt.
# Flask/pytest for the SQL injection lab live in sql-injection-lab/requirements.txt.
#
# See SETUP.md for setup instructions and the dependency contribution policy.
